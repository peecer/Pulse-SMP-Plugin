# Pulse SMP Plugin

Archive and release repository for the Pulse SMP plugin and its optional client-side command-key mod.

## Current recommended server build

- `releases/server/Pulse-1.8.1.jar`

## Repository layout

- `releases/server/` — current/final server releases
- `archive/server/` — historical server builds kept for rollback/reference
- `client/` — optional client-side keybind mod builds
- `client/source/` — source ZIPs for the client keybind mod
- `SHA256SUMS.txt` — checksums for every archived artifact
